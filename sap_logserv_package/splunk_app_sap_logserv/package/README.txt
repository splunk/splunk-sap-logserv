Splunk App for SAP LogServ
==========================

Dashboards and analytics for SAP LogServ data.

This app provides search-time field extractions, dashboards, and macros for
SAP log data ingested by the Splunk TA for SAP LogServ (splunk_ta_sap_logserv).

Install this app on search heads. For data collection and index-time processing,
install the Splunk TA for SAP LogServ on your deployment server and heavy forwarders.
